## 系統核心指標 (800MW 定案版)
- **在管容量目標**：**800 MW (0.8 GW)** ｜ 占全台 2030 國家目標 31.2GW 之 **2.56%**
- **FY2030 營收**：新台幣 **3.01 億元**（運維服務 2.11 億 ＋ 整新整改工程 0.90 億）
- **營業利益率**：**14.9%**（營業利益 **4,498 萬元**）
- **總人力編制**：**63 人**（現場 28 人 / 14組 ＋ 間接後勤 35 人）
- **現場人均承載**：**28.6 MW / 人**（35.7 場 ｜ 透過五大例行工作 100% 外包卸除 70% 體力勞動）
- **專項修繕儲備金**：**422 萬元**（按 2.11 億服務營收之 2.0% 提撥）
- **西海岸據點**：6 處（南區 400MW 50%、中區 240MW 30%、北區 160MW 20%）

## 兩大深度戰略支柱
1. **高綠電價格（CPPA 5.5 ~ 6.5+ 元/度）下整新整改四大商模**：
   - **ESCO 發電增益分潤**：出資換裝高效模組/逆變器，增發度數五五拆帳 3~5 年，綁定 10~15 年 OM。
   - **老電廠低估收購轉供 CPPA**：以 FIT 低殘值收購老電廠，整新拉升 PR 至 85%（增發 20%），解約轉供科技大廠 CPPA (5.8~6.5元)，賺取 25% EPC 工程毛利與 AM 績效分潤！
   - **組串逆變器速贏整改 (Quick-Win)**：淘汰老舊集中式逆變器，改換多路智慧 MPPT 組串逆變器，增益 8~12%，2.5 年回本。
   - **原地超裝擴容 (Overbuild)**：原有交流併網饋線不變下，DC/AC 提高至 1.35，早晚與陰天全額滿載，總度數提升 25~35%。
2. **輕資產外包矩陣——明確五大分包項目**：
   - **模組定期清洗**：100% 外包專業水洗隊/機器人（年 2~4 次，3~4 萬/MW/次）。
   - **除草水保**：100% 外包在地割草班（年 3~4 次，1.5~2 萬/MW）。
   - **法定高壓電氣定檢**：100% 外包甲級電氣檢驗業/機電顧問（每半年/每年出具法定報告）。
   - **基礎外觀隨工點檢**：外包協力廠進場清洗割草隨工拍照初篩。
   - **支架防腐與大修土建**：專業鋼構土木商專案分包。
   - *現場工程師卸除 70% 體力勞務，專責 P1 4hr 急修、高壓排障與驗收，人均產能衝上 28.6 MW！*
