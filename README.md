## 系統核心指標
- **在管容量目標**：1,000 MW (1GW) ｜ 占全台 2030 國家目標 31.2GW 之 3.2%
- **FY2030 營收**：新台幣 3.79 億元（運維服務 2.65 億 ＋ 整新整改工程 1.14 億）
- **營業利益率**：14.6%（營業利益 5,519 萬元）
- **總人力編制**：77 人（現場 34 人 ＋ 間接後勤 43 人）
- **現場人均承載**：30 MW / 人（突破 92% 負荷瓶頸，清洗外包 &ge; 25%）
- **西海岸據點**：6 處（高雄總部/主倉、台南一、台南二、彰化、屏東/嘉義、桃園）
